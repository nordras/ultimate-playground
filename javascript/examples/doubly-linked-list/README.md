# Doubly Linked List examples

This folder contains a simple doubly linked list implementation and usage examples in JavaScript.

## Files

- `doublyLinkedList.js`: implementation with append/prepend/find/remove and two-way traversal.
- `example-basic.js`: basic insert, remove, and traversal operations.
- `example-deque.js`: using a doubly linked list as a deque.
- `example-history.js`: simple undo/redo navigation history.

## Run examples


```bash
node example-basic.js
node example-deque.js
node example-history.js
```
